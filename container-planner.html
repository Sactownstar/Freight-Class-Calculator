Container load planner

Floor-loaded, no-stack estimate for boxed units like appliances. Enter each product. Add a quantity to plan it, or leave it empty to see how many more will fit in the space left.

Container specs (inside size, inches and pounds)

Container sizes are typical starting values and vary a little by container and shipping line, so adjust them if yours differ. The default 44,000 lb cargo limit is a common US road weight cap, not the container’s rating. When a product leaves a partial row, the next product is placed in the gap beside it if it fits across the width; if it is deeper than that row, the extra depth is counted. Dunnage, door clearance, weight distribution, and your carrier’s rules aren’t included.
